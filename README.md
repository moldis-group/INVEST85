# INVEST85

This repository is a part of the supplementary information of the study

_When optimized geometries are not optimal: Implications for inverted singlet–triplet gap predictions_   
Atreyee Majumdar, Elamathi Selvan Samynathan and Raghunathan Ramakrishnan    
Preprint (2026)             
[https://arxiv.org/pdf/2611.06871](https://arxiv.org/pdf/2611.06871)         

# content
The CSV file [energies.csv](energies.csv) contains the S<sub>1</sub>, T<sub>1</sub>, and S<sub>1</sub>-T<sub>1</sub> energies and  oscillator strengths (f) calculated using the L-CC2/aug-cc-pVDZ (AVDZ) method on the corresponding ωB97M-D4 optimized geometries. It also contains the HOMO and LUMO energies and HOMO–LUMO gaps (H–L gap) for all 85 INVEST systems. 

The folder [INVEST-85_wB97M-D4_def2TZVP_geometries](INVEST-85_wB97M-D4_def2TZVP_geometries) contains the optimized geometries of all 85 INVEST systems at the ωB97M-D4/def2-TZVP level.
